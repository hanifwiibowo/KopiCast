# Dashboard Peramalan Harga Kontrak Berjangka Kopi

Dashboard Streamlit untuk peramalan harga kontrak berjangka kopi arabika (Coffee C Futures)
dan robusta (Robusta Coffee Futures) menggunakan LSTM berbasis Attention Mechanism.

Proyek Akhir, Departemen Statistika Bisnis, Fakultas Vokasi, Institut Teknologi Sepuluh Nopember.

Menjalankan secara lokal:

    pip install -r requirements.txt
    streamlit run app.py
